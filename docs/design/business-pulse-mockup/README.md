# Business Pulse design mockup

Static, standalone design reference for the "Business Pulse" look (Modernist
design system: Archivo typeface, warm red-orange accent, square corners,
hairline borders, uppercase micro-labels). Open `PROV-AI Demo.dc.html`
directly in a browser to click through the mockup's five views (Map, Data
sources, To verify, Case file, AI assistant) and the call/voice modal.

This is a reference only. It is not wired into the running app and is not
part of the build; the actual product is the Streamlit app under `app/`,
restyled to match this design system (see `app/ui/theme.py`).
